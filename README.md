Aplicación web académica para la gestión de renta de vehículos.

**Tecnologías:** Laravel 12, Tailwind CSS, Alpine.js y MySQL.

**Mi aporte:**

- Coordinación del repositorio principal y colaboración del equipo mediante ramas y Pull Requests.
- Implementación de autenticación con Laravel Breeze y control de acceso para administradores y empleados mediante middleware personalizado.
- Desarrollo de los módulos de vehículos, categorías, usuarios y perfiles.

Aplicación móvil académica para el seguimiento de actividad física, nutrición y hábitos.

**Tecnologías:** React Native, Expo y Firebase.

**Funcionalidades del proyecto:**

- Autenticación con Firebase Auth.
- Persistencia de información en Firestore.
- Seguimiento de datos en tiempo real.
- Funcionalidades sociales y recordatorios.
